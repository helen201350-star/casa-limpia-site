# CASA LiMPiA — тестовая версия сайта

Исходная проверенная версия: **v09 от 22 октября 2026 г.**

`index.html` — полностью автономный сайт со встроенными фотографиями, стилями и JavaScript.

## Просмотр

Открой `index.html` в браузере на компьютере. Для просмотра на телефоне используем GitHub Pages после включения публикации репозитория.

## Правки с Codex

Codex должен прочитать `AGENTS.md` **до любых изменений**. При изменении сайта сохраняем новые версии и не меняем другие артикулы.

## Публикация на GitHub Pages

1. В настройках репозитория открой **Settings → Pages**.
2. В разделе **Build and deployment → Source** выбери **Deploy from a branch**.
3. Выбери ветку `main`, папку `/(root)` и нажми **Save**.
4. Открой адрес Pages, показанный GitHub. Публикация общедоступна в интернете.

Резервные копии сайта и утверждённые каталожные изображения сохраняем отдельно на Google Диске; файлы здесь не заменяют этот архив.
